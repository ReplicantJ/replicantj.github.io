# Personal site

Source for a personal resume/portfolio site — a static React app, currently mid-redesign and pending a move to its permanent host.

## Stack

- **Vite** + **React 19** + **TypeScript**
- **Motion** / **GSAP** for animation

## Run locally

```bash
npm install
cp .env.example .env.local   # optional overrides
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

Some MIT-licensed animation patterns are adapted from [React Bits](https://reactbits.dev/). Front-end code only — no secrets live in this repo.
